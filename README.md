# QNX Driver Drowsiness & Attention Monitoring

## Project
Real-time driver drowsiness detection using a lightweight CNN
and QNX RTOS on Raspberry Pi.

## Classes
- awake
- sleepy

## ML Pipeline
Dataset
→ Preprocessing
→ CNN Training
→ Evaluation
→ ONNX Export
→ QNX Deployment

## Target
Raspberry Pi 4 + QNX RTOS

## Model Input
64 × 64 grayscale image

## Model Output
awake / sleepy
